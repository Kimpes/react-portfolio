Welcome to my portfolio application! It's a work in progress, but as of right now it has a mostly functional CMS handling both portfolio entries and their associated images. It's written in React and Express, and utilises SQLite, Multer, Cors.

Functions that are in the works are: a refined design, a more intuitive image editing infrastructure, a login system.

Instructions for setup of application:

- run the command "npm I" inside both folders /frontend and /backend
- run the command "npm run dev" inside the root folder to launch the app
